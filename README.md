# Student Registration System

A responsive student registration and management application built with React and Vite. It allows users to register students, manage student records, view statistics, and import or export student data.

## Live Demo

[Open Student Registration System](https://student-registration-system2.vercel.app)

## Features

- Student registration with form validation
- Prevent duplicate student IDs
- Search students by name, ID, and department
- Edit and delete student records
- View individual student details
- Alphabetical sorting by student name
- Dashboard with student statistics
- Department statistics and progress bars
- Export student records as JSON
- Import student records from JSON
- Data persistence using browser localStorage
- Responsive and modern dark-themed interface

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/zinedinmujibu/student-registration-system.git
```

### 2. Enter the project folder

```bash
cd student-registration-system
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Data Storage

This application uses browser localStorage to save student records.

**Note:** Records are stored locally in each browser. They are not shared between different users or devices.

## Deployment

The application is deployed using Vercel.
